# Fibra Flow

Quero criar um sistema workflow onde cadastro a uma obra de implantação de fibra óptica e passo a atualizar todas etapas previstas, essa ferramenta terá as etapas de planejamento, projetos, protocolos de licenças, licenças para obras, fornecimento de materiais, dependência extra, execução, baixa da obra e aceitação. Deve ser um sistema que consigo ter acessos que podem cadastras e acessos de usuários que podem atualizar.
